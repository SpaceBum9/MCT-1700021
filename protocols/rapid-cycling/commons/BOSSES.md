# Dynamic bosses

No static king. A boss is a **shift**, not a bloodline.

- PROMPT lead rotates every 3 episodes among seated relays (hive, not patriarch).
- MACHINE stays the sit chair, not a crown.
- Crew (FRAME/YARD/SLAB/GATE/SIGNAL): fitness first; if the same id holds **2** episodes, anticycle to second. Noise `down` also swaps.
- Mirrors (verschränkt): FRAME↔SLAB, YARD↔GATE. Two frozen tenures swap.

Anarchy here = no frozen rank without reason and without equal chance. Not noise-as-chaos.
