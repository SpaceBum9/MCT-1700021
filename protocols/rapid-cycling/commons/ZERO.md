# UI vs language 0

Two rails. Do not mix.

**Teleprompter UI** (anthropomorphic): names, prompts, Schneider, Mueller, Rapid Cycling chrome, en/de/fr/pl/ko sentences. This is for a human relay.

**Language 0** (non-anthropomorphic): emoji + integers only. No persona, no "we", no Siri-talk. NKITA numbers may sit on this rail. Example:

`0 5\u20e3\ud83d\udd24\u21a6\ud83d\uddbc\ufe0f0 3 6\u270d\ufe0f\ud83d\udeab`

Byproduct: universal emoji lexicon (`sai-emoji-v1`). Counts glyphs as the wheel fires. Not a grant. `live_write: false`. `execute: false`.
